# Sobre a empresa

A Alenna é uma startup recém-criada que está desenvolvendo uma plataforma SaaS de IA para tradução técnica e revisão científica de artigos acadêmicos. Fomos aprovados no Programa Centelha (parceria SEBRAE/FINEP) e recebemos aporte para tirar o produto do papel e lançá-lo comercialmente — é justamente nessa etapa que estamos montando o time de desenvolvimento.

# Sobre a vaga

Buscamos um(a) desenvolvedor(a) fullstack para atuar no backend (Django) e frontend (Next.js) do produto, implementando novas funcionalidades e evoluindo um código-base já em produção.

**Faixa salarial:** R$ 2.900 a R$ 3.900/mês

**O que buscamos:**
- 1+ ano de experiência fullstack, com Python/Django e React/Next.js
- Django REST Framework
- Next.js (App Router), TypeScript e Zod
- Tailwind CSS e bibliotecas de componentes (shadcn/ui ou similar)
- Celery e processamento assíncrono (Redis ou SQS)
- PostgreSQL, incluindo migrations
- Hábito de escrever testes automatizados
- Conforto para trabalhar em um código-base já existente, seguindo convenções já documentadas pelo time

**Diferenciais (não obrigatórios, mas contam pontos):**
- Integração com gateway de pagamento (Stripe, Pagar.me, Mercado Pago ou similar) em produção
- Modelagem de assinatura/billing recorrente
- Autenticação multifator (2FA/TOTP)
- Familiaridade com LGPD/GDPR
- Experiência em SaaS B2B/B2C multi-tenant
- Testes de carga (Locust, k6)
